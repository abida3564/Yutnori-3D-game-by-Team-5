# 📌 Project Overview

Yutnori is one of Korea's oldest traditional board games. This project recreates the game as an interactive web application while preserving its original gameplay mechanics.

Players can enjoy Local Matches with multiple teams or challenge the AI opponent. The game includes customizable player profiles, multilingual support, responsive design, and a modern user interface.

---

# ✨ Features

| Feature | Description |
|---------|-------------|
| 🎲 Traditional Gameplay | Implements the original Yutnori game rules |
| 👥 Local Match | Supports 2, 3, and 4 team gameplay |
| 🤖 AI Match | Play against the computer |
| 🌐 Multi-language Support | English, Korean, and Bangla |
| 👤 Custom Player Profile | Set your own display name |
| 🖼️ Custom Avatar | Upload and change player image |
| 🛣️ Multiple Routes | Choose shortcut paths at board junctions |
| ⚔️ Capture System | Capture opponent pieces to earn an extra throw |
| 🔁 Extra Turn | Extra throw for **Yut**, **Mo**, and captures |
| 🏆 Final Ranking | Displays 1st, 2nd, and 3rd positions |
| 📱 Responsive Design | Works on desktop, tablet, and mobile |
| 🔍 Board Zoom | Zoom in and zoom out controls |
| 🎯 Finished Pieces Tracker | Automatically tracks completed pieces |
| 🎨 Modern UI | Clean interface with smooth animations |

# 🎲 Yut Throw Values

| Throw | Movement |
|--------|----------|
| Do | +1 |
| Gae | +2 |
| Geol | +3 |
| Yut | +4 + Extra Throw |
| Mo | +5 + Extra Throw |
| Back-Do | −1 *(If a piece is already at the starting position, Back-Do has no effect.)* |

# 🚀 Getting Started

### Option 1

Open the project by running:

```
index.html
```

using any modern web browser.

### Option 2 (Recommended)

Run the project with **VS Code Live Server**.

1. Open the project folder.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
